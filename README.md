# Minesweeper (Terminal)

A terminal-based Minesweeper game written in Python.

## Features

- Three difficulty levels
  - Easy (8x8)
  - Medium (12x12)
  - Hard (16x16)
- Random mine generation
- Win/Lose detection
- Input validation
- Modular code structure

## Planned Features

- Adjacent mine counter
- Automatic opening of empty cells
- Flag system
- Better game over screen
- Replay option
- Timer
- Score system

## Requirements

- Python 3.10+
