# Terminal Minesweeper

A terminal-based Minesweeper game written in Python.

## Features

* Three difficulty levels:

  * Easy: 8x8
  * Medium: 12x12
  * Hard: 16x16

* Random mine generation

* Automatic mine count calculation

* Recursive flood fill system for opening empty areas

* Win and lose conditions

* Input validation

* Colored terminal interface

## How It Works

The game uses a 2D grid system to manage the board.

Flood fill is implemented using recursion to automatically open connected empty cells.

## How to Run

Run the game with:

```bash
python main.py
```
